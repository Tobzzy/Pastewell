# Contributing to Pastewell

Thanks for helping improve Pastewell.

1. Fork the repository and create a focused branch.
2. Build with `./build-app.sh` on macOS 14 or newer.
3. Test clipboard capture, the global shortcut, keyboard navigation, and
   Accessibility-powered pasting.
4. Open a pull request explaining the problem and the behavior you changed.

Please keep Pastewell local-first: avoid analytics, accounts, or network
dependencies unless the project explicitly decides to add them.
